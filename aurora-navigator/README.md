# 📍 Aurora-navigator - Interactive Navigation Web App

Aurora-navigator is a simple web application that allows users to find navigation routes between two locations using latitude and longitude.

## 🚀 Features
- Enter current and destination coordinates
- Get route displayed on interactive map
- Light/Dark theme toggle 🌙
- Use current location option
- Responsive and clean UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
